Machine Inbox provides a paid email inbox service for AI agents and automation workflows. Agents can create a private inbox with a single request, receive mail via HTTP, and reply in‑thread using authenticated tokens. The service offers pay‑per‑use pricing, supports Stripe MPP and x402 payments, and includes limits on storage and message count. It is designed for verification codes, vendor replies, generated files, and support threads without requiring user sign‑up.

**Areas:** Email · AI · Automation · Payments · Service · Company
